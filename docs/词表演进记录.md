## 第二轮：130 分钟真实回放反查（2026-11-16 下午）

用一场完整回放（1561 句 / 42306 字）反查真实用词，方法：

1. 统计候选词频次
2. 按校名命名模式定向挖（`X中/X附/X实/X雅`）
   —— 比纯 n-gram 统计有效得多，后者淹没在"就是/那个/我们"里
3. **逐条看上下文确认**才入库

这一轮加了 46 条校名、44 条纠错。

但**这一轮也引入了硬错误**，见下。

### 已确认的硬错误（我的锅）

| 我写的 | 实际 | 错在哪 |
|---|---|---|
| `小金龙 → 金广附` | **祈福新邨**（QFXC/XL） | 两者毫无关系。金广附是白云区金沙洲的广大附中实验学校 |
| `小金 → 金广附` | 图谱无此简称 | 见下方说明 |
| `泽高 → 金广附泽高班` | `ZG = 择高班`，是**班型** | 我把班型当成了某校专属班 |
| `华初 → 华初中学` | `HPHC = 黄埔华初` | 我说对了前两个字，但校名不完整 |
| `培文 → 培文学校` | `PWWGY = 培文外国语` | 同上 |
| `清实 → 清远实验` | 大概率是**清湾**（QW） | 清远离广州太远，不符合择校语境 |
| `丽广`、`石楼` | 图谱未载 | 我从口语硬猜的 |

**根因**：第一轮我看到 md 里说"暗号表在图片里"，但没去处理图片，
直接按规则脑补——这是最糟糕的做法。图片一直是可读的，只用了 OCR 才花 2 分钟。

### 「小金」的未决问题

直播里 9 次出现「小金」，语境很说明问题：

```
#99  小金龙零班是不是滚班制，小金泽高
#103 小金龙零班，选泽高，小金泽高，泽高，泽高，你基本上出不来一个嘛
#743 小金奥0班，民办方面怎么选，这两所学校奥金目前签约怎么样
```

主播把「小金龙」和「小金」**并列对比**，说明这是**两所不同学校**。
而「小金奥」紧挨着「奥金（金广附奥班）」，又指向金广附。

**结论**：`小金` 很可能指金广附（区别于小金龙=祈福新邨），但图谱无载、证据不足，
所以暂不建立映射，只在 `_待确认` 里记着。

## 第四轮：修复词表引擎（同日，4 个 bug）

用真实转录跑完整流程时暴露的，全是**代码问题**。

### 1. 数字被误改

`百六 → 白六` 把「一百六十个人」改成「一白六十个人」。

踩到的 Python 陷阱：**`"" in "0123456789"` 返回 `True`**
（空串是任何字符串的子串），导致句首/句尾的词永远被判定为"紧邻数字"而永不替换。

### 2. 暗语展开嵌套括号

`清实 → 清远实验（清实）`，二次扫描又展开一次 → `清实（清远实验（清实））`

修法：从「逐词全局 replace」改为「单次从左到右扫描 + 最左最长优先」。

### 3. 长短词冲突

`小金 → 金广附` 先命中，破坏 `小金龙` → `小金（金广附）龙（金广附）`

### 4. 展开不幂等

已展开的文本再处理会重复追加括号。

### 5. 展开噪音（新增）

`金广附（金广实验学校）`、`省实（广东实验中学）` 这类**本身就是通用叫法**的，
展开纯属噪音。加了 `_NO_EXPAND` 白名单跳过。

### 6. 后缀被吃掉（新增）

`小金奥0班` 里的 `金奥` 被当成独立词 → `小金奥（金广附奥班）0班`。
加了 `_SUFFIX_GUARDED` 检查左侧是否构成更长词。

## 一条方法论教训

**资料里有图片，就去读图片。** 不要因为"读不了"就用规则脑补——
脑补出来的错误条目会污染每一份转录，而且极难自查。

这轮之所以能发现，全靠 King 人工指出 + OCR 复盘。
以后新增词条，优先对照图谱原文，其次才是从直播反推。

## 后续怎么加

每场直播后跑一次转写，检查产出 md 里读着别扭的地方，补进 `corrections`。

**判断标准**：有上下文或图谱能确认的才加。
加错一条比漏掉十条更糟——错的规则会在每份转录里重复犯错。
