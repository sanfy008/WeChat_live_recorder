## 三、在当前项目中的可应用场景

结合当前项目（`wxlive` 微信直播录音转写流水线）的架构，这份排行表可以在以下 4 个环节直接发挥作用：

1. **补充领域词表（`lexicon/xsc.json` 与 `wxlive/lexicon.py`）**
   - 原词表已覆盖校名与部分特色班，但缺少大量细分重点班名称和区属简称，例如：
     - 特色班名：`HHL煌上煌`、`七中四叶草`、`十六中君武`、`三中大扬鹰`、`东风实验青云`、`五中张衡`、`绿翠南雪`、`南武剑吴`、`江外钻石`、`西外金苹果`、`天外2+4`、`华实博学`、`烧鸡择奥/高`、`烧鸡梦想`、`白雅冠冕`、`白省格致`、`京师奥基`、`华初秋实`、`华初春华`、`黄广T5`、`东外清苗`、`花执灵格风重点`、`朝阳国信`、`为明元培`、`荔广数基`、`南广小奥数创`、`番附信创`、`广理工英才`、`培正次zdb`、`86中住海`、`17中弘毅`。
     - 新缩写/别名：`65江高`、`六万课改`（六中万胜围）、`琶执`（琶洲执信）、`军纪课改`（黄埔军校纪念中学）、`亚铁铁英`、`广实`、`雅初岭南1/2`。
   - 将这些词补充进 `schools` / `terms` / `codes` 后，ASR 提示词（`build_prompt_hint`）和暗语展开（`expand_codes`）会更准，能减少“四叶草”“剑吴”“张衡”“煌上煌”“灵格风”等专有名词的同音误听。

2. **增强 LLM 纠错上下文（`wxlive/postprocess.py` → `fix_errors`）**
   - 直播中主播常把同校不同校区/公办民办混着说（如越秀公办「省实南山」vs 荔湾「荔省南山」vs 白云公办「省实永平南山」vs 白云民办「白省南山」）。
   - 将这些带区属/班型的专名喂给 `fix_errors(vocabulary=...)`，可避免 LLM 纠错时把「白省南山」误改回「省实南山」或「省越南山」。

3. **提升要点整理质量（`wxlive/postprocess.py` → `build_digest`）**
   - 目前 `build_digest` 的 prompt 仅要求输出「提到的学校与评价」。
   - 若将这份**梯队（神/豪/一线/准一线/二线/准二线）+ 行政区 + 公办/民办**映射作为参考背景注入（或作为结构化字典做后标注），LLM 生成的直播纪要就能自动标出学校所属梯队与公办/民办属性，方便后续横向对比和家长决策。

4. **消歧参考（对应 `lexicon/xsc.json` 的 `_待确认`）**
   - 表中明确区分了：番禺一线民办 **`小金龙零班`**（祈福新邨）与白云一线公办 **`金广附奥班`**（金广实验学校），进一步印证两者分属不同区域和学校体系，可作为后续校名消歧的权威依据。
